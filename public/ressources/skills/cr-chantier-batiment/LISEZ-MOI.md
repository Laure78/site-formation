# Skill « CR de chantier » — installation

Skill offert par Laure OLIVIÉ — Formatrice IA spécialisée BTP · www.laureolivie.fr
Tuto complet : https://www.laureolivie.fr/ressources/tuto-cr-chantier

## Contenu
- `SKILL.md` : les instructions du skill (section 0 à personnaliser)
- `scripts/generer_cr.py` : met en page le CR Word (charte, tableaux, pagination)
- `references/` : trame de dictée, exemple de calibrage, format des données
- `assets/` : déposer ici votre logo sous le nom `logo.png`

## Prérequis
- Abonnement Claude payant (Pro, Max, Team ou Enterprise)
- Settings → Capabilities : activer « Code execution and file creation »

## Installation (5 min)
1. Dézipper, ouvrir `SKILL.md`, remplir la **section 0 – Paramétrage entreprise** (nom, couleur, police, vocabulaire, destinataires, délai d'observations).
2. Ajouter votre logo dans `assets/logo.png` (facultatif).
3. Re-zipper le dossier `cr-chantier-batiment`.
4. Sur claude.ai : Settings → Customize → Skills → importer le zip. Vérifier que le skill est activé.

## Utilisation
Collez la transcription de votre dictée (et le CR précédent si vous l'avez), puis écrivez « fais le CR ».
Claude produit le CR Word, le mail d'envoi et la liste des points à confirmer.
Règle d'or : relire avant envoi (noms propres, dates, montants).
