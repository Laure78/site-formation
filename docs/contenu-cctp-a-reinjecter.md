### Faut-il Claude Pro ou ChatGPT Plus ?

> Les deux conviennent. Claude Pro est souvent plus confortable sur les PDF longs. ChatGPT Plus suffit si vous découpez bien les pièces. Je vous aide à trancher selon vos habitudes en session.

### La formation est-elle adaptée aux marchés privés (pas que publics) ?

> Oui. Les marchés privés utilisent souvent les mêmes familles de pièces. La méthode reste : lire le périmètre technique, croiser le bordereau, sécuriser le mémoire.

*Proche de la FAQ landing AO (« marchés publics comme privés ») mais ancrée CCTP / bordereau / mémoire.*

### Comment se déroule une session intra ?

### Quel est le délai pour organiser une formation ?

## 2. Programme « 4 modules CCTP » (angle différent du programme Cowork NIV-02)

NIV-02 = 3 modules Claude Pro / Cowork / skills. Ci-dessous = découpage **CCTP / DPGF / anti-hallucination** (potentiellement utile en article ou encart « méthode lecture pièces »).

### Module 1 — Comprendre l’IA appliquée aux CCTP : opportunités et limites (1 h)

- Ce que l’IA fait bien sur un CCTP : synthèse, grille de risques, questions ouvertes.
- Ce qu’elle ne fait pas : valider un DTU, signer une offre, remplacer le regard métier.
- Protocole anti-hallucination : sources, doubles lectures, traçabilité.

### Module 2 — Méthode d’analyse en 4 étapes : préparation, extraction, risques, croisement DPGF (1 h)

- Préparer et nommer les pièces : CCTP, RC, CCAP, DPGF.
- Extraire les exigences par lot avec références de paragraphes.
- Scanner les clauses pénalités, délais, interfaces entre lots.
- Croiser ligne à ligne avec le bordereau pour éviter les oublis de chiffrage.

### Module 3 — Atelier pratique sur vos CCTP réels (1 h)

- Application sur extraits anonymisés de vos marchés.
- Relecture croisée chargé d’affaires / conducteur de travaux.
- Liste des points à clarifier avec le maître d’œuvre avant offre.

### Module 4 — Industrialiser : créer vos GPTs et projets spécialisés (1 h)

- Modèles de prompts réutilisables par type de lot.
- Paramétrage de projets (Claude) ou GPTs (ChatGPT) pour votre vocabulaire.
- Charte interne : données sensibles, validation humaine, archivage.
