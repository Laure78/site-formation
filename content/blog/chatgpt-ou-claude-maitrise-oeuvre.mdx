## Ce qu'ils savent faire tous les deux

- rédiger et reformuler (CCTP, courriers, observations de visa, comptes rendus) ;
- synthétiser des documents longs (DCE, rapports, notes) ;
- comparer des pièces (offres, fiches techniques au regard du CCTP) ;
- produire des tableaux exploitables ;
- travailler dans des espaces de projet où vous gardez vos documents de référence et vos consignes.

Les deux évoluent tous les mois : ce comparatif porte sur les usages, pas sur des numéros de version.

## Comparatif par usage de maîtrise d'œuvre

| Usage | Ce qui compte | Notre retour terrain |
|---|---|---|
| CCTP, notices, pièces écrites longues | qualité rédactionnelle, longs documents | Claude est souvent apprécié pour la rédaction longue et la fidélité au texte source |
| Compte rendu de chantier à partir d'une dictée | rapidité, usage mobile | les deux fonctionnent ; ChatGPT est très répandu sur mobile |
| Analyse des offres / dépouillement | tableaux, rigueur, traçabilité | les deux, avec une grille de critères fournie par vous |
| Visa des documents d'exécution | lecture croisée CCTP / document | les deux ; vérification humaine indispensable |
| Images, rendus, communication | génération d'images | ChatGPT intègre la génération d'images |
| Méthodes répétitives du cabinet | consignes réutilisables | projets dans les deux outils ; les Skills de Claude permettent de packager une méthode (voir [notre tuto](/blog/tuto-skill-claude-maitrise-oeuvre)) |

## Le même prompt, dans les deux outils

Testez vous-même avec un vrai document anonymisé :

```
Contexte : voici l'article [X] du CCTP du lot [intitulé] et la fiche technique transmise par [ENTREPRISE A].
Rôle : assistant de maîtrise d'œuvre.
Action : liste les exigences du CCTP et indique pour chacune si la fiche y répond, avec la citation. Écris « à vérifier » en cas de doute.
Format : tableau | exigence | réponse de la fiche | statut |.
Ton : factuel.
```

Comparez la précision des citations, le respect du format et les « à vérifier ». C'est le meilleur critère de choix pour vos usages.

## Nos conseils pour décider

1. **Partez de vos 3 tâches les plus chronophages** et testez-les dans les deux outils sur une semaine.
2. **Regardez la confidentialité de l'offre** avant la qualité de réponse (voir [IA et confidentialité en maîtrise d'œuvre](/blog/ia-confidentialite-donnees-maitrise-oeuvre)).
3. **Standardisez un outil principal pour l'équipe** : une bibliothèque de prompts commune vaut mieux que deux outils mal maîtrisés.
4. **Les versions gratuites suffisent pour découvrir** ; les usages intensifs sur documents longs justifient souvent une offre payante.
