## En bref

- Anthropic propose **des cours en ligne gratuits** sur **Anthropic Academy** ([anthropic.com/learn](https://www.anthropic.com/learn)) — cet article retient **quatre modules** particulièrement utiles aux **conducteurs de travaux** et **collaborateurs de PME du BTP**.
- Le parcours minimal pertinent (Claude 101 · AI Capabilities · AI Fluency Foundations · Introduction to Claude Cowork) représente environ **6 à 7 heures**, gratuit, avec certificat en fin de module selon les cours.
- Les autres modules du catalogue ciblent surtout les **développeurs** (API, MCP, Claude Code, clouds) ou des **profils non BTP** — vous pouvez les ignorer au début.
- **Aucun cours ne couvre les DCE, CCTP, mémoires techniques ou CR de chantier** : la **spécialisation BTP** se construit avec la pratique terrain et une formation métier dédiée.
- Parcours conseillé **par profil** ci-dessous (conducteur de travaux, chargé d’affaires, assistant·e, dirigeant·e, responsable QSE).

## Anthropic Academy : c’est quoi exactement ?

L’**Anthropic Academy** est la plateforme de formation gratuite éditée par **Anthropic**, créateur de **Claude**. Les cours sont accessibles depuis [anthropic.com/learn](https://www.anthropic.com/learn) ou la plateforme [Skilljar Anthropic](https://anthropic.skilljar.com/).

Les cours sont **gratuits**, majoritairement **en anglais** (souvent avec sous-titres), avec inscription sur la plateforme — format vidéos, texte et quiz ; durées variables.

C’est une source **éditoriale sérieuse**. En revanche, les contenus restent **génériques** : vous opérez vous-même le lien avec **DCE**, **mémoire technique**, **compte rendu de chantier**.

## Pourquoi un conducteur de travaux ou un collaborateur PME BTP devrait s’y intéresser ?

Sur les chantiers que j’accompagne — **FFB Grand Paris**, **CSFE**, **FFB Île-de-France** — trois constats reviennent souvent :

**Constat 1 — Le temps administratif dévore le terrain.** Un conducteur de travaux consacre une **part importante** du temps à l’administratif : CR de chantier, mails de relance, situations, OS, réserves, DGD — du temps ni sur le chantier ni avec les équipes.

**Constat 2 — Peu de pros BTP ont encore essayé l’IA.** Une partie significative du secteur **n’a pas encore testé** un assistant conversationnel — souvent par manque de temps pour démarrer. **Une heure gratuite**, le soir ou le week-end, permet de franchir le pas sans engagement.

**Constat 3 — Il y a beaucoup de bruit.** Beaucoup parlent de ChatGPT ; **Claude** est souvent très pertinent sur les **documents longs** (CCTP volumineux, DCE). Suivre un cours publié par **Anthropic** clarifie les usages sans passer par du marketing tiers.

Pour ces raisons, **Anthropic Academy** est une **première marche gratuite**. Encore faut-il **trier** les modules : cet article garde **quatre cours** alignés terrain.

## Les 4 cours gratuits vraiment utiles pour le BTP

### Claude 101 — le point de départ obligatoire

**Durée : ~1 heure · Niveau : débutant**

Usage quotidien : question, reformulation, synthèse, analyse de fichier. Bon réflexes : **contexte**, **format de sortie**, **itérations**.

**Transposable au BTP :**

- Demande claire (« rédige une relance fournisseur », « synthétise cette réunion »).
- Conversation pour affiner le résultat.
- Détection des erreurs et correction.

**À tester après le cours :** coller un mail client confus et demander une synthèse en **trois points**.

### AI Capabilities and Limitations — le cours qui vous protège

**Durée : ~1 heure · Niveau : débutant**

Ce que l’IA **peut** et **ne peut pas**, hallucinations, fiabilité.

**Critique en BTP :**

- Ne jamais prendre un calcul ou une citation normative sans contrôle humain.
- Vérifier DTU, références contractuelles, formulations juridiques.

Ce cours aide à **garder la responsabilité** sur ce que vous signez ou diffusez.

### AI Fluency: Framework & Foundations — la méthode professionnelle

**Durée : 3 à 4 heures · Niveau : intermédiaire**

Méthode en **quatre leviers** (souvent présentés comme **Delegation · Description · Discernment · Diligence**) : quoi déléguer à l’IA, comment formuler, comment juger le résultat, quelles vérifications avant envoi.

**Essentiel pour le terrain :** passer du gadget au **gain de temps mesurable** — même logique que dans les formations OFC **adaptées au BTP**.

### Introduction to Claude Cowork — pour qui gère beaucoup de documents

**Durée : ~2 heures · Niveau : intermédiaire**

**Cowork** : manipuler **Excel**, **Word**, **PDF**, dossiers multi-fichiers, comparaisons de versions, extraction structurée.

**Utile en PME BTP** lorsque vous recevez des **dce zippés**, plusieurs formats, carnets de réserves, plannings — Cowork aide à **orchestrer** sans tout ouvrir à la main.

**À tester après le cours :** charger un dossier récent et demander un tableau **lot → vigilance → délai** (toujours sous votre validation).

## Les 13 autres cours : utiles ou non pour vous ?

Dans la majorité des cas, **vous pouvez les ignorer au début**. Synthèse indicative :

| Cours | Pour qui c’est | Verdict pour vous |
| --- | --- | --- |
| AI Fluency for educators | Enseignants | Ignorer |
| AI Fluency for students | Étudiants / alternants | À signaler aux apprentis |
| AI Fluency for nonprofits | Associations | Hors cœur de métier |
| Teaching AI Fluency | Formateurs | Méta-cours |
| Building with the Claude API | Développeurs | Ignorer |
| Claude Code 101 | Développeurs | Ignorer |
| Claude Code in Action | Développeurs | Ignorer |
| Introduction to agent skills | Développeurs | Ignorer |
| Introduction to subagents | Développeurs | Ignorer |
| Claude with Amazon Bedrock | Équipes IT | Ignorer |
| Claude with Google Cloud's Vertex AI | Équipes IT | Ignorer |
| Introduction to Model Context Protocol | Intégrateurs | À transmettre à l’éditeur de votre ERP / CRM |
| Model Context Protocol: Advanced Topics | Développeurs avancés | Ignorer |

**MCP (Model Context Protocol)** : mécanisme d’interconnexion entre assistants et logiciels — utile à connaître côté **éditeur métier** ; côté terrain, ce qui compte est surtout **l’usage** derrière une interface déjà intégrée.

## Parcours conseillé par profil métier

### Conducteur de travaux

**Claude 101 → AI Capabilities → AI Fluency Foundations**

Gains typiques : **comptes rendus**, tri de **mails**, premières **synthèses** de courriers sensibles. **Cowork** devient intéressant dès que les **volumes documentaires** explosent sur plusieurs chantiers.

**Temps indicatif : 5 à 6 h** sur deux semaines.

### Chargé d’affaires / appels d’offres

**Claude 101 → Cowork → AI Fluency Foundations → AI Capabilities**

Les **DCE entrants** poussent à prioriser **Cowork**. Le module **AI Fluency** aide à structurer des **mémoires techniques** — comme sur la [formation IA conducteur de travaux](/formation-ia-conducteur-travaux). Le lien vers le **catalogue complet** figure dans la section « Se former avec OFC » ci-dessous.

**Temps indicatif : 6 à 7 h.**

### Assistant·e administrative / office manager BTP

**Claude 101 → AI Fluency Foundations → Cowork**

Gains : **correspondance**, mise en forme, **préparation de dossiers**. **AI Capabilities** reste utile mais un peu moins centrale si vous produisez peu de contenus techniques à responsabilité directe.

**Temps indicatif : 5 h.**

### Dirigeant·e PME BTP

**Claude 101 → AI Capabilities → AI Fluency Foundations**

Objectif : **cadrer ce que les équipes peuvent faire**, où sont les **risques**, comment **encadrer** sans devenir expert prompt. Cowork peut attendre un **projet de déploiement** réel.

**Temps indicatif : 5 à 6 h.**

### Responsable QSE / méthodes / bureau d’études

**Claude 101 → AI Capabilities → Cowork → AI Fluency Foundations**

**Capabilities** et **Cowork** aident lorsque vous manipulez **normes**, **référentiels** ou versions successives de procédures — toujours avec **double lecture humaine**.

**Temps indicatif : 6 à 7 h.**

## 3 prompts BTP à tester pendant les cours

### Prompt 1 — Compte rendu de réunion de chantier (pendant Claude 101)

```text
Tu es conducteur de travaux pour une entreprise de bâtiment.
À partir des notes brutes ci-dessous, rédige un compte rendu de chantier
structuré avec :
1. Avancement par lot
2. Points bloquants et décisions prises
3. Réserves émises avec nom du responsable
4. Prochaines étapes avec délai

Ton : professionnel, factuel, à destination du maître d'œuvre.
Format : 1 page maximum.

[Coller ici les notes brutes de la réunion]
```

### Prompt 2 — Analyse rapide d’un extrait de CCTP (pendant AI Capabilities)

```text
Tu es responsable d'études pour une entreprise du BTP.
Analyse l'extrait de CCTP ci-dessous et identifie :
1. Les clauses techniques contraignantes (DTU, normes, certifications exigées)
2. Les risques d'interprétation ou contradictions
3. Les sujétions d'exécution non chiffrées explicitement
4. Les points à clarifier en variante ou en question écrite

Format : tableau Markdown à 4 colonnes (Clause / Exigence / Risque / Action).

[Coller ici l'extrait de CCTP]
```

### Prompt 3 — Relance fournisseur (méthode AI Fluency)

```text
Tu es assistant administratif pour une PME du BTP.
DÉLÉGATION : rédige la relance ci-dessous.
DESCRIPTION : sous-traitant carrelage, commande SOM-2026-018 du 12 mars,
livraison promise 28 avril, toujours pas livrée, chantier bloqué.
DISCERNEMENT : ton ferme mais professionnel, mention du préjudice
sans menace, demande de date ferme sous 48h.
DILIGENCE : termine par une phrase indiquant que je relirai avant envoi.

Format : objet + corps de mail, signature à remplacer par mes coordonnées.
```

## FAQ — Cours gratuits Claude AI pour le BTP

**Les cours Anthropic Academy sont-ils vraiment gratuits ?**
Oui : l’accès aux parcours listés sur la plateforme Anthropic / Skilljar est gratuit ; aucune carte bancaire requise pour l’inscription standard.

**Faut-il un compte Anthropic pour suivre les cours ?**
Un compte **Skilljar** suffit pour les modules en ligne. Pour pratiquer dans **Claude**, créez un compte **Claude.ai** (gratuit possible pour tester).

**Les cours sont-ils en français ?**
Majoritairement en **anglais** avec sous-titres. Pour du **français + métier BTP**, orientez-vous vers une **formation IA pour les pro du BTP** dispensée en français.

**Combien de temps pour un pro du BTP ?**
Environ **5 à 7 h** pour les quatre modules recommandés, sur **2 à 3 semaines**. L’intégralité du catalogue représente bien plus — inutile de tout enchaîner.

**Les cours permettent-ils de répondre à un AO seuls ?**
Non pour une **réponse complète** : ils ne remplacent pas la **méthode AO**, les **clauses CCTP**, ni la **validation interne**.

**Par quel cours commencer en conducteur de travaux ?**
**Claude 101**, puis **Capabilities and Limitations**.

**Les certificats Anthropic sont-ils reconnus Constructys ?**
Non : pas d’éligibilité OPCO en tant que telle. Il faut une **action Qualiopi** chez un organisme certificateur — voir conditions sur la page financement Constructys ci-dessous.
